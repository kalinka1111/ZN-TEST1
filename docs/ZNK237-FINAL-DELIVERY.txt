📦 INSTALLATION & SETUP

═══════════════════════════════════════════════════════════════════════════════════

1. External Storage (Recommended)
   
   mkdir -p /Volumes/ZNKdata/znk_storage
   chmod 755 /Volumes/ZNKdata/znk_storage

2. Launch Application
   
   Open in browser:
   file:///Volumes/ZNKfly/ZNKstable2/ZNKsystem-app/APPZNKLite/studios/znk237-launch.html

3. Initialize Modules
   
   • Launcher loads all 5 core modules
   • Verifies system integrity
   • Checks external storage connectivity
   • Displays "Ready" status

4. Access Admin Dashboard
   
   • Click "Launch Admin" button
   • Opens znk237-admin-dashboard.html
   • Start creating workflows & managing content

═══════════════════════════════════════════════════════════════════════════════════

⚙️  CONFIGURATION

═══════════════════════════════════════════════════════════════════════════════════

In znk237-launch.html, modify:

    config = {
      externalStoragePath: '/Volumes/ZNKdata/znk_storage',  // Mount point
      storageQuota: 50 * 1024 * 1024 * 1024,                // 50 GB
      env: 'production'                                      // or 'development'
    }

In znk237-admin-dashboard.html, access via Settings section

✨ SPECIAL FEATURES

═══════════════════════════════════════════════════════════════════════════════════

Unified Design System
  Every component uses the same CSS variables, ensuring:
  • Consistent spacing & typography
  • Easy theming (change 1 variable, affects all components)
  • Fast load times (CSS-based, no JS overhead)
  • Mobile-responsive by default

Intelligent Storage Layering
  Workflows persist across multiple levels:
  1. In-memory cache (fastest)
  2. localStorage (fallback, instant)
  3. External volume (persistent, large files)
  → Never lose data, always responsive

Ecosystem-Aware Moderation
  Keyword scanner validates key names, so:
  • Only scans ZNK ecosystem storage (znk_* keys)
  • Doesn't interfere with external web content
  • Prevents false positives on library code
  • Admin dashboard shows alerts for suspicious content

Offline-First Architecture
  • WhatsZNK works without internet
  • Messages queue locally, sync when online
  • Workflows save immediately (no server needed)
  • Perfect for remote/unreliable networks
