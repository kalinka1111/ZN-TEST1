📖 Comment utiliser ce launcher

  1. Installez Electron (une seule fois) :
    npm install electron --save-dev
  2. Lancez votre application dans le terminal :
    electron . --port=5000
  3. Revenez ici et cliquez sur "🔄 Vérifier"
  4. Cliquez sur "⚡ Lancer" quand le bouton devient vert

⚠️ Important : L'application doit tourner sur localhost:5000
